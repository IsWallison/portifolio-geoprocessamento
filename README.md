# Jornada: Geoprocessamento (QGIS) para Licenciamento Ambiental - RJ

Objetivo final: atuar como prestador autônomo de geoprocessamento para licenciamento
ambiental no RJ, captando clientes pelo LinkedIn (serviços de alta demanda e baixa complexidade).

## Pastas
- 00_plano_e_log       -> Plano Mestre, Diário de Bordo e tarefas (exporte os docs do Claude para cá)
- 01_dados_brutos      -> MDE, hidrografia, imagens, limites (dados originais, nunca editar)
- 02_dados_processados -> recortes, declividade, buffers
- 03_projeto_qgis      -> .qgz e GeoPackage (.gpkg)
- 04_mapas             -> PDF/PNG dos layouts
- 05_relatorio         -> relatório técnico em PDF
- 06_scripts           -> PyQGIS / Python
- 07_linkedin          -> rascunhos de posts, perfil, banners
- 08_comercial         -> catálogo de serviços, propostas, lista de consultorias
